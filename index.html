Honest data handling

No hidden auto-send.

Generated handoffs may be processed by Gemini, Mistral, or Groq. The backend does not intentionally log or permanently store chat text. Anonymous transfer metadata is stored for reliability analytics, but telemetry never includes chat text or generated summaries. A protected users table keeps only a sequential user number plus lifetime and current UTC-day successful-summary counts. One raw transcript remains locally available for diagnostics for up to 24 hours.

Good to know

Questions,
answered.

Does Cap Context send messages for me?
No. It pastes the generated Context Carry into the destination composer and focuses the tab. You review the text and decide whether to press Send.
When does my conversation leave the page?
Only after you choose a destination and start the transfer. Generated handoffs may be processed by Gemini, Mistral, or Groq. Simply opening or closing the picker sends no chat content.
Which AI sites are supported?
Claude, ChatGPT, Gemini, Grok, and DeepSeek.
How do I install Cap Context?
Install it from the Chrome Web Store. The same listing works in both Chrome and Brave, with automatic extension updates and no Developer mode.
What if automatic paste fails?
Cap Context keeps the generated handoff available in a manual-copy dialog, so you can still paste it into the destination yourself.
