# Privacy Policy for Cap Context

This Privacy Policy explains how Cap Context ("we", "our", or "us") handles user data.

## Information Collection and Use

- **Data Transmission**: Cap Context sends selected chat conversation text to our backend **only** when the user explicitly clicks the "summarize" action/button.
- **Processing**: The backend processes this text using the Mistral API to generate the requested conversation summaries.
- **Purpose**: Data is utilized solely to provide the summarization functionality.

## Data Retention and Security

- **Temporary Processing**: We do not store chat content permanently. Data is processed in-memory for the duration of the API call to generate your summary.

## Data Sharing and Sale

- **No Sale of Data**: We do not sell user data to third parties.
- **No Advertising**: We do not use user data for advertising purposes.
