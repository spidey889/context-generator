# Cap Context — keep going

Cap Context is a browser extension that carries a conversation from one AI to another. This film is for people who have already put work into a chat and reach a limit before finishing.

Angle: a Kyoto trip is nearly planned. Claude knows the person's base, food preferences and pace. Claude reaches its limit when they ask for day three. Cap Context carries those details to ChatGPT; the same short follow-up now gets an answer that respects them.

Hook: immediately enter an unmistakable, large Claude conversation already in progress. The only text during the demonstration belongs to the UI or the conversation. The payoff is the answer's continuity, followed by a separate title card.

Tone: warm, minimal, premium. Use the local Cowork reference's paper, decisive camera moves, enlarged component views, expressive cursor and quiet synchronized sound. Keep Cap Context's actual dark/lilac interface intact.

Fresh production DOM is exported from `extension/platform-content.js`. Native controls are not repainted. Host chat shells and the sample conversation are authored illustrations; no private account, paid API or live chat submission is needed.
