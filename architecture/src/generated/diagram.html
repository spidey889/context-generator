The transfer

  • Claude, ChatGPT, Gemini, Grok and DeepSeek share the same handoff.
  • Opening the picker reads no chat text. Choosing a destination begins capture and parallel tab preparation.
  • Native credentials stay in the source page. The summary API receives the serialized transcript.
  • Capture and paste pin chat identity; navigation cancels the attempt. Send remains the user's action.

Carries and recovery

  • At most 1,200 trimmed characters: exact carry built in the source page, with no summary request.
  • Larger chats use a two-minute worker cache or the configured provider chain under a shared 270-second budget.
  • Default routes: Ling, Gemini Flash, Gemini Flash-Lite, then Ministral. Paused routes require explicit enablement.
  • Exhausted providers or unavailable funded budgets return the exact transcript. Worker/backend failure can recover from verified source text.

What persists

  • The local Latest Run receipt keeps the exact transcript for 24 hours and never stores the generated summary.
  • The worker's durable outbox sends only bounded metadata. Optional telemetry failures cannot block a transfer.
  • Server-signed receipts prove summary work and model attribution; source-local carries have no fresh server receipt.
  • This diagram reflects pinned repository source. Hosted deployments and Web Store releases are separate states.
