# Changelog

A short history of decisions and regressions that matter when changing the code. Read the relevant section of [LOGIC.md](LOGIC.md) for current behavior, ownership and checks; use this file when you need to understand why an approach changed. Entries describe source changes unless deployment is explicitly recorded. Extension packaging, Web Store publication and backend deployment are separate.

## 2026-10-05

- **Destination chat ownership (T01).** Restricted prepared-tab reuse/activation and content insertion to new-chat surfaces. Added a navigation latch through paste retries, focus and delayed recovery, preserving initial landing redirects and same-route editor remounts. Added automated regressions for saved/pending chats, focus navigation and away-and-back recovery; browser checks were explicitly excluded.

## 2026-10-04

- **Free composer layouts fixed.** Live free ChatGPT and Claude Reply layouts exposed assumptions about responsive-footer markers and where model controls live. Updated the platform adapters to use the observed native slots; composer replacement also clears the detached orb's active state. Focused regressions and installed-Brave fixtures covered narrow layouts, drafts and Reply transitions, with live placement checks. Web Store publication remains separate.
- **Agent references clarified.** Reorganized `LOGIC.md` around component ownership, contracts and targeted checks, and removed the dated scraping audit. Added [HANDOFF_SKILL.md](HANDOFF_SKILL.md) as a reusable handoff workflow with pinned upstream source and MIT license; it is separate from generated session handoffs and the backend prompt.

## 2026-10-03

- **Authenticated served-model attribution.** Added signed v3 receipts and `transfers.model` because client labels cannot prove which model served a summary. First attribution survives retries and worker restarts; older events remain unattributed. Migration `20261003124307` was applied and Edge version 10 deployed; backend production release and extension distribution remain separate. See [the migration](supabase/migrations/20261003124307_add_served_model_to_transfers.sql) for compatibility and preservation rules.
- **Extension 1.4.8 prepared.** Bumped the source manifest and corrected the stale README version after deterministic, database, installed-Brave and live-summary checks passed. Built and source-compared a local ZIP. This records release preparation, not Web Store publication.
- **Provider choice settled on Ling.** Comparative accuracy runs favored Ling over Apodex; Apodex still omitted explicit prohibitions after prompt improvements and was removed. The Ling-first source landed on `master`. Earlier audit instructions to hold the combined Ling/Apodex merge describe a superseded experiment. Use [current routing](docs/provider-fallbacks.md); consult [the comparison](docs/openrouter-primary-comparison.md) and [the accuracy pass](docs/summary-accuracy-pass.md) for the decision evidence and remaining factual errors.
- **Removed obsolete routing machinery.** Retired Groq, OrcaRouter, unused Google routes and Gemini daily-health/Redis skip tracking. They added stale switches, receipt fields and alternate paths; each request now starts from its configured routes. Historical provider orders and restoration instructions in earlier commits are superseded.
- **Orb design settled.** The owner chose simple hover enlargement over the cursor-proximity bounce and retained the original picker timing over the faster orb-origin trial. Tightened the backdrop opening to the solid artwork after the surrounding disc was rejected. The opening solved native ancestor stacking limits while keeping the real orb in its native slot. See [picker/placement code](extension/platform-content.js).
- **Picker focus corrected.** Removed both orbs from Tab navigation at the owner's request. Dismissal returns focus to the native composer; a closing animation or resize must not steal it from a reopened picker or another control. Regressions exercise actual focus and the dismissal boundary in [the content-script tests](test/platform-content.test.js).
- **Optional storage stopped breaking transfers.** A pre-merge audit reproduced successful summaries being blocked or discarded by telemetry storage faults. Decoupled that path and retained signed receipts through independent session persistence. The same review fixed Edge accepting impossible calendar dates; Edge version 10 includes that correction. See [background delivery](extension/background.js) and [verified telemetry tests](test/verified-telemetry.test.js).
- **Database cleanup completed.** Removed unused reporting views, the redundant transfer ID and reporting timestamps; renamed `transfer_events` to `transfers`. Historical RPC/receipt compatibility and retained data were preserved through migrations and restore checks. Pending events were not converted into failures. The first user's lowercase `naruto` name is an explicit owner-requested exception. See [migrations](supabase/migrations) and [recovery guidance](supabase/README.md).

## 2026-10-01 to 2026-10-02

- **Verified work replaced paste claims as the counting authority.** Added server-signed summary receipts because a client-reported paste cannot authenticate backend work. The telemetry repair also covered retries, terminal outcomes, relay authentication and backup replay. SQL remains the counter authority; the rollout retained older receipt/RPC callers. See [telemetry operations](supabase/README.md).
- **Users reset and daily accounting corrected.** The owner explicitly authorized a users-only counter reset while preserving transfer history. Later migrations moved daily accounting to India calendar days, sampled dates after locks to avoid midnight races, and excluded empty-chat attempts from user failures. Replaying pre-reset attempts must not recreate cleared counts; preserve the migration boundaries when restoring old backups.
- **Inline placement replaced generic geometry assumptions.** Native toolbar audits reproduced hidden duplicate controls masking valid anchors, popup controls moving the orb, and composer replacement retaining stale ownership. Each platform received its own inline validation; Claude became inline-only after its temporary fallback was rejected. A later Grok regression showed that narrowing the observer missed ancestor-class restoration. See [placement regressions](test/platform-content.test.js) before sharing adapter behavior.
- **Transfer timeout became cancellation.** The old page lock could expire while late capture, summary or paste work continued. Propagated one attempt deadline through continuations and recovery, and retained cancellation metadata across worker restarts. Optional telemetry persistence cannot extend that deadline.
- **Test execution became faster.** Consolidated duplicate/source-text cases and introduced simulated clocks instead of wall-clock waits. October 3 follow-ups extended scoped clocks in fresh VM fixtures and cleaned up leaked badge timers while preserving behavioral assertions and native stalled-HTTP-body reads. Follow the existing timing fixtures when extending regressions; old suite counts are not acceptance criteria.
- **Approved picker and homepage changes consolidated.** The owner chose backward gold Speed trails over forward streaks. The picker header orb became a website link, with its later Tab exclusion recorded above. The homepage was reduced to the extension install flow, demo and handoff illustration; editable film sources and credits remain in [brag/README.md](brag/README.md).

## 2026-09-29 to 2026-09-30

- **Useful summaries stopped failing on formatting.** Strict shape checks had rejected usable context; unconditional nonempty acceptance then allowed empty scaffolding and refusal-only replies. Added a separate content gate, kept structural flags advisory, and added exact source-local recovery for backend/worker failure. See [the acceptance policy](docs/summary-validation.md) before changing validation.
- **Paste verification caught missing middles.** Replaced three short sample matches after they could miss a truncated middle. Verification now checks ordered content while tolerating formatting; activation checks also recover cleared editors and preserve newer drafts. See [paste regressions](test/platform-content.test.js).
- **Hidden-tab completion stopped hanging.** Source repaint suspension could leave an already-pasted transfer pending. Bounded the final paint wait and released it when hidden, so destination activation and receipt saving could finish.
- **Progress estimates became honest about overruns.** Replaced the fixed summary animation with a size-based display estimate. It stops when the summary arrives and explicitly reports overruns; it does not drive provider budgets. Latest Run gained readable receipt copying without copying raw chat text.
- **Telemetry schema and migration history were reconciled.** A missing live cancellation constraint caused production telemetry rejection. Fixed that before Edge deployment, removed unused public-role grants, and matched recorded migrations to hosted history. Backup restore later had to handle both whole-file and per-statement migration records. See [database checks and recovery](supabase/README.md).

## 2026-09-27 to 2026-09-28

- **Fresh JSON capture moved from experiments to the default picker path.** DOM virtualization motivated native-history adapters for all five platforms. Failed fast capture gained one announced DOM fallback in the same attempt instead of failing the transfer or opening a second destination. Toolbar capture and explicit opt-out retained the DOM path. The pre-integration source is tagged `v1-before-fast-capture`.
- **JSON audits fixed identity and data loss.** Reproduced wrong-chat/away-and-back navigation, stale hook readiness, lost pasted cards and whitespace rewriting. ChatGPT additionally needed voice-text and expired-session handling; DeepSeek needed broader supported source-file extensions. Fixture/Brave regressions demonstrated the fixes, not universal native-history completeness. Current extraction boundaries and schema evidence are in [LOGIC.md's capture section](LOGIC.md#capture).
- **Claude extraction moved away from per-type rejection.** Early JSON experiments rejected tools or allowed a special paired-tool exception. Replaced those rules with direct own-turn text/thinking and supported pasted-card extraction, so unrelated tool blocks no longer reject otherwise usable conversations. Nested tool/search/file content remains outside that extraction scope.
- **Extension styling survived page CSP and Dark Reader.** Reports of plain handoff labels exposed reliance on page style tags. Moved picker/handoff styles into extension-owned constructed sheets and scoped palette protection, retaining cleanup of owned resources.
- **Preview and production diverged.** The production alias still served an older commit while the reordered fallback chain existed only in preview. An explicit production-target redeploy and real receipt verified the fix. Future release claims need live alias/source evidence.
- **Retired artifacts left the runtime path.** Removed the one-time apology-notice service and tracked extension ZIPs. Preserved the old homepage and standalone skill under [legacy/](legacy/) as reference artifacts; the backend does not read that skill.

## Keeping this useful

- Add a short dated bullet for a behavior change, important regression, compatibility boundary or decision that a future agent could otherwise repeat. State what changed and why; link detailed evidence when available.
- Consolidate related iterations into the final decision. Keep rejected approaches only when their reason helps future work. Skip routine branch merges, script-load IDs, cosmetic iterations, repeated test totals and command transcripts.
- Put current invariants, thresholds, provider settings, ownership and check commands in `LOGIC.md` or the relevant focused doc. Update those when behavior changes instead of copying their contracts here.
- Record a deployment only when it was verified, identifying the component. Keep historical evidence clearly historical when a later decision supersedes it.
