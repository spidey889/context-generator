# Changelog

A short history of decisions and regressions that matter when changing the code. Read the relevant section of [LOGIC.md](LOGIC.md) for current behavior, ownership and checks; use this file when you need to understand why an approach changed. Entries describe source changes unless deployment is explicitly recorded. Extension packaging, Web Store publication and backend deployment are separate.

## 2026-10-07

- **Claude picker survives native layout races.** Two regressions reproduced automatic dismissal on a resize immediately after opening and during destination selection. Claude's picker now belongs to the current chat instead of transient editor/toolbar wrappers. Placement updates preserve its open state, focus and Speed choice through remounts, viewport changes and composer gaps, reattach the same orb, and remove stale backdrop click-through holes. Choosing stays within the viewport; selected-transfer geometry remains frozen. Explicit dismissal and actual chat changes still close the picker, including navigation while the composer is absent. The Brave fixture now checks those paths and full expanded/reply editor replacement; other providers retain their existing lifecycle. Validation passed 121 content-script checks and the isolated Brave transfer/database fixture. Its geometry probe now verifies the 36px layout slot separately from the open orb's 1.08 visual scale.

- **Actual model reporting is separate from verified summary accounting.** A successful Gemini-to-Claude transfer's local receipt identified `gemini-3.5-flash-lite`, while its database row had no model or server receipt. The one-second optional attribution path can omit signing context when storage stalls. The ingress/RPC now accepts a bounded `reported_model` and stores it with `model_verified=false`; authenticated v3 attribution takes priority and remains immutable. Client reports never increment verified-summary counters. The migration preserves existing rows, authenticated models, counters and private access; old 10–14-argument callers remain compatible. Server schema/validators must deploy before the extension starts emitting the new field.
- **Extension reports actual results across unsigned paths.** Summary-completed and terminal telemetry now carry the final serving model independently of receipt signing and Latest Run writes. Cache reuse retains its original model; source-local tiny and backend-error recovery report `local-direct`. Delayed progress, retries and restart preserve attribution without replacing proof/model pairs or terminal outcomes. Timer regressions cover the one-second storage timeout followed by an unsigned model report; the Brave database fixture checks the new 15-column schema and authenticated/report agreement.

- **Gemini optional metadata no longer disables fast text capture.** The owner's latest local Gemini-to-DeepSeek receipt reported `unsupported` before successful DOM fallback. In Gemini that reason came only from strict attachment-label parsing, which treated every optional user-metadata entry as a file. Two bridge regressions reproduced complete paginated text and mixed supported uploads being discarded. Unknown metadata now remains excluded while verified user/selected-assistant strings and confirmed quoted filenames survive; file-only unknown input still falls back. Gemini hook readiness advances to v8 so reload recovery replaces the old serializer. The existing Gemini CI fixture now includes unknown metadata on an older page. Diagnosis used local receipt metadata, code and automated fixtures without computer use.

- **Gemini JSON capture and response-menu fallback fixed.** Three regressions reproduced native histories being rejected for an omitted candidate-selection field, late installation requiring earlier RPC traffic, and DOM preparation clicking response controls. Fresh capture now uses native bootstrap routing when no template exists and follows parent candidate IDs across paginated regenerated replies. Updated fixtures omit the optional field rather than hiding the incompatibility. DOM expansion excludes popup triggers, menus/dialogs and response actions; Gemini restricts expansion to authored content. Gemini hook readiness advances to v7. Validation passed 195 focused checks, the long-scroll regression and isolated Brave JSON/fallback transfers with zero response-menu clicks. The Gemini browser fixture now uses its native composer and both cases join CI. Live-account completeness and Web Store publication remain separate.
