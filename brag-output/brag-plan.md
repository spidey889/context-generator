# Cap Context — first draft

Angle: your work survives the moment Claude reaches its limit. Carry the conversation to ChatGPT and ask only the next question.

Cap Context is a browser extension that captures the current AI conversation, prepares portable context, and pastes it into another AI. It is for people doing sustained work across AI chats. The distinguishing visual is the real destination picker, followed by capture → summary → paste and the same work continuing. The sample conversation is a notes-app launch: freelancers, October, a free trial, and a warm, direct voice.

Core message: **Switch AIs without re-explaining everything.**

Tone: polished, restrained, premium. Warm paper, native Claude cream and ChatGPT white, the extension's actual dark picker/handoff, restrained purple, soft original music. Landscape, 1920 × 1080, 60 fps, 24 seconds. No voiceover.

The destination still requires a user Send click. No exact latency claim is made.
