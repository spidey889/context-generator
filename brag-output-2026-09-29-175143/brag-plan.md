# Cap Context — second cut

The first 62-second Kyoto film remains untouched. This is a new edit of the same honest Claude → Cap Context → ChatGPT story, with a stronger musical arc and more decisive camera choreography.

## Angle and hook

The viewer is already inside a substantial Claude conversation. Claude knows Sanjo, early walks, vegetarian food and a relaxed pace; a request for day three hits its usage limit. Cap Context carries that knowledge into ChatGPT, where the same short request gets a coherent day-three answer.

The first two seconds should show a large, believable conversation, not a title. The final message still appears only after the work leaves the frame: **Switch AIs without re-explaining everything.**

## Reference-derived choices

The owner's local Claude Cowork film was re-examined at dense intervals. At 3–5 seconds a single toggle is isolated, the pointer arrives, and the selected half changes after the click. At 16.75–18.42 the camera jumps from a whole UI into a composer fragment large enough to crop beyond the frame. At 43–45.67 a progress card remains attached to the chat before the camera pushes into its step list. At 57.08–57.42 the whole app becomes a composer close-up in roughly a third of a second. The UI clears before the separate beige type close. These are *motion principles*, not source footage, audio or a layout to trace.

This cut uses a visible causal chain: target → pointer arrival → short dwell → press → UI reaction → held result. A few moves become faster and larger; text holds remain generous. The native ChatGPT tile receives a deliberate macro push, and the native handoff card appears over the Claude conversation instead of on an empty interstitial.
